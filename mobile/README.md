# KSR Cars: React Native app

A native Android (and iOS-ready) app built with Expo SDK 57 / React Native. It talks to the
same server as the website (`https://ksr-self-drive-cars.onrender.com` by default) and reuses
the booking rules, IST time slots, prices and validation from `../shared`.

| For | Screens |
|---|---|
| Customers | Fleet with 12/24 hr prices and filters · Book a car (day and time chips, live "booked" hints, clash alternatives) · Booking confirmation · Check a booking |
| Staff | Sign-in · Two-step verification (set up with one tap into the authenticator app) · Dashboard (new requests, today's pickups and returns, overdue) · Bookings search · Booking detail: confirm, reject, cancel, no-show, close, record payments, call or WhatsApp the customer |
| Everything else | **Full admin** opens the web admin inside the app, already signed in: handover and return with photos and signature, documents, fleet, customers, reports, settings, staff |

**Settings** (home screen footer) changes the server address, e.g. `192.168.0.6:3000` for a
computer on the office Wi-Fi.

Package name `com.ksrselfdrivecars.mobile`: different from the website app
(`com.ksrselfdrivecars.app`, in `../android`), so both can be installed side by side.

## Build an APK on this computer

Needs Android Studio (for Java and the Android SDK). From `mobile/`:

```bash
npm install
npm run apk          # → ../release/ksr-cars-react-native.apk
```

The first build downloads the Android NDK and takes 10–20 minutes; later builds are quicker.

**Windows:** React Native's native build creates file paths longer than Windows' 260-character
limit, and the build tool in Android's CMake 3.22.1 stops there ("Filename longer than 260
characters"). Use the EAS cloud build below, or build on macOS/Linux.
The APK is signed with a debug key: fine to share with testers (WhatsApp, Drive), not for
the Play Store. `android/` is generated by `expo prebuild` and git-ignored: change native
settings in `app.config.ts`, not in `android/`.

## Build in the cloud with EAS (download link and QR code)

```bash
npx eas-cli@latest login                                   # free Expo account
npx eas-cli@latest build -p android --profile preview      # APK, shareable install link
npx eas-cli@latest build -p android --profile production   # .aab for Google Play
npx eas-cli@latest submit -p android                       # upload to Play (needs a Play service account)
```

The first `build` asks to create the Expo project and an Android upload key (EAS keeps it
safely). Over-the-air updates for JavaScript changes: `npx expo install expo-updates`,
`npx eas-cli@latest update:configure`, then `npx eas-cli@latest update --branch production`.

## Develop

```bash
npm run start        # Metro; press "a" for an emulator or scan with a development build
npm run typecheck
npm test             # runs the app's helper tests with the main project's Vitest
```

Raise `KSR_VERSION_CODE` (env) and `version` in `app.config.ts` for every Play Store release.
